Execution order

Five nodes carry a reel from a project folder to an MP4. Sockets are typed, so the order is enforced by the graph rather than by convention. Editing decisions are not made in any of these nodes — they are made in the Storyline sidebar panel, which writes shots.csv.

Set Narration→ PROJECT → Project→ Align→ ALIGNMENT → Shot Table→ SHOTS → Subtitles→ SUBS → Render Reel

Cost profile. Align is the only slow step (~90 s, Whisper). Project, Shot Table and Subtitles are disk reads and complete in under a second. Render Reel is CPU-bound at roughly 61 ms/frame at 1080×1920 — a 142-second reel took 301 s including alignment.

Category memoacts/audio — the voice

Seven nodes, and a workflow of its own that runs before the reel: example_workflows/voice.json. Every one takes an AUDIO and returns an AUDIO, so the chain can be cut anywhere and any node bypassed. The sample rate and channel count are never changed, and neither is the length — except by Pitch / Time, whose whole job is length. That is the reason this is a separate graph: Align measures every timing in the reel against the recording it hears, and the alignment cache keys on that file's mtime, so a chain that rewrites the recording on every Queue would cost a ninety-second re-alignment for turning a knob. The DSP is memoacts_core.voice on pedalboard (Rubber Band + JUCE), scipy and pyloudnorm; all three are imported lazily, so a machine without them loads the rest of the pack and fails here with the install command.

MemoActsAudioPitchTimeMemoActs — Pitch / Timememoacts/audio

Independent tempo and pitch change through Rubber Band, formants preserved — so a faster read stays the same person. The only node here that changes the length of the take, which is why the pace is decided in this graph and nowhere after it. A tempo_factor of 1.0 with no pitch shift returns the input untouched rather than re-encoding it.

ParameterTypeDefaultNotes

MemoActsAudioSpeechDenoiseMemoActs — Speech Denoisememoacts/audio

Steady hiss and hum, reduced without stripping the room. spectral_gate builds a noise floor from the 10th percentile of each frequency bin and applies a Wiener-style soft mask, which is what avoids the musical artefacts of a hard gate; noise_gate is pedalboard's, blunt, for bad takes. strength 0 is passthrough.

ParameterTypeDefaultNotes
audioAUDIO—
methodCOMBO"spectral_gate"spectral_gate · noise_gate
strengthFLOAT0.50 … 1, step 0.05. Past ~0.7 the floor breathes between words, which is more distracting than the hiss was.
→ AUDIO
MemoActsAudioDeEsserMemoActs — De-essermemoacts/audio

Downward compression on the sibilance band only: a 2nd-order high-pass splits the take, the high band is compressed against a channel-linked envelope, and the two are summed again — so the rest of the voice is untouched and the stereo image does not shift when gain is pulled.

ParameterTypeDefaultNotes
audioAUDIO—
freqINT70002000 … 16000, step 100. Clamped to 99% of Nyquist, so it cannot be set above the rate.
threshold_dbFLOAT-8.0-60 … 0, step 0.5. Measured inside the band, not on the whole take.
ratioFLOAT3.01 … 20, step 0.1. Above ~8 the S disappears rather than softens.
→ AUDIO

MemoActsAudioAutoTuneMemoActs — Auto-Tunememoacts/audio

Pitch pulled toward a scale — drift tuned, and a processed sheen. YIN tracking is written out in memoacts_core.voice.track_f0 rather than taken from librosa, whose numba paths are broken against this environment's NumPy; the correction is carried across unvoiced gaps and one-pole smoothed before it reaches the stretcher. Not a hard snap, and it cannot be made into one: Rubber Band follows a pitch curve to about 1–2 Hz (measured: correlation 0.95 at 1 Hz, 0.00 at 8 Hz) while speech moves at 4–8 Hz, which is why retune_ms floors at 150. Length is pinned back to the input, because a varying curve makes the stretcher drift a few ms and this audio is the reel's master clock.

ParameterTypeDefaultNotes
audioAUDIO—
keyCOMBO"C"The twelve chromatic roots.
scaleCOMBO"chromatic"chromatic · major · minor · pentatonic_major · pentatonic_minor
retune_msFLOAT300.0150 … 1500, step 10. Lower is stronger; the floor is the backend's limit, not taste.
strengthFLOAT0.70 … 1, step 0.05. 0 returns the input untouched.
max_correctionFLOAT2.00.5 … 12 semitones. Caps how far a note may move, so a mis-tracked octave cannot throw a word.
preserve_formantsBOOLEANtrueOff makes the correction audible as a character change.
→ AUDIO  ·  length always equals the input

MemoActsAudioLoudnessMeterMemoActs — Loudness Meter (LUFS)memoacts/audio

ITU-R BS.1770 integrated loudness and sample peak, measured on the first take of the batch and passed through unchanged. Instagram and TikTok normalise to about -14 LUFS: land near it and the platform leaves the reel alone. Under 0.4 s there is less than one BS.1770 block to integrate and the report says so instead of guessing.

Category memoacts — reel pipeline

Nine nodes. All but Align and the two override nodes are output nodes: they run on Queue and return a text or video preview rather than only a socket.

MemoActsSetNarrationMemoActs — Set Narrationmemoacts

Writes an AUDIO tensor to <project>/sources/narration.wav as 24-bit PCM, preserving the incoming sample rate and channel count. Creates the project directory tree if the name is new. Moves any other narration.* in sources/ to archive/, because find_narration() takes the first match alphabetically and narration.mp3 would otherwise shadow the WAV. Skips the write when the encoded bytes are identical, so re-queuing does not invalidate the alignment cache. Reports remaining prerequisites: scene count in script.md, image count in sources/images/.

ParameterTypeDefaultNotes
audioAUDIO—Output of the voice workflow, or a plain Load Audio.
projectSTRING""Folder name under projects/. Rejects path separators and leading dots.
create_if_missingBOOLEANtrueFalse refuses an unknown name instead of creating it.
→ PROJECT  ·  output node  ·  cache key: written file's mtime + size
MemoActsProjectMemoActs — Projectmemoacts

Reads the project folder and reports it: which recording was found and its duration, image count, scene count, and which media each scene resolved to. ParameterTypeDefaultNotes

MemoActsAlignMemoActs — Alignmemoacts

Forced alignment of the known script text against the recording, via stable-ts. Does not transcribe — it computes when each word of the existing script is spoken, which is why subtitles reproduce the script verbatim. Cached on the mtimes of script.md and the recording, so downstream edits cost nothing. Falls back to proportional spans if the aligner is unavailable, flagging the result as estimated.

MemoActsRenderReelMemoActs — Render Reelmemoacts

One ffmpeg pass: per-frame crops streamed from PIL, subtitles burnt via libass, narration muxed without re-timing. Memory is constant in reel length — no chunking, no concat. Reports progress per frame with the frame attached, which also provides cancellation. Output is numbered and never overwritten. With sfx connected, the bed is summed with the narration using amix …:normalize=0; the default would drop the voice 6 dB.

Category memoacts — sound design

Four nodes around a third table, sfx.csv. The generator sits between SFX Prompt and Save SFX rather than inside either, so swapping the audio model changes nothing else in the graph. The narration is read but never written.

Category memoacts/page

Seven nodes producing a typed document plate. The typesetting is deterministic and is not generated: eleven hundred characters of exact text at 7440×10240 is outside what a local model sets without inventing some of it, and the reel needs named anchors at 1:1 scale. The model is used only for the paper surface and the pencil hand.

Defined once in nodes_types.py. Only a path travels on PROJECT; every step re-reads the folder, so a file changed on disk is picked up by the next run rather than hidden behind a cached payload.

shots.csv columns

One row per scene you want to say something about; every column but shot is optional and blank means "keep the default". A row whose shot cell starts with # is a comment and is ignored entirely.

ColumnDecides
shotWhich scene: 1-based number, S01, or the cue timecode written in the script.
mediaBare filename, resolved across images · composites · maps · videos.
inIn-point for footage. 2:14 or seconds.
motionOne of the nine presets. Blank cycles a default by scene number.
rateZoom fraction. Ignored when a focus or path is set.
anchorcenter or top.
speedFootage playback rate; 0.4 is slow motion.
focuscx cy w in source fractions — one destination window. Honoured by static · zoom_in · zoom_out only; the pans ignore it and warn.
pathSeveral stops: t:cx,cy[,w] space-separated, t a fraction of the scene. Width carries forward; two stops sharing a t hold. Overrides preset, rate and focus. schema 1.6
labelCorner tag, held label_hold seconds from the scene's start.
creditSource line, held for the whole scene.
effectsPreset name for this scene alone.
notesNot read by the pack.

Constraints that shape every framing decision

Three rules in the geometry, worth knowing before a shot is planned. Two are arithmetic and one is policy.

A crop cannot leave its source. The window is a rectangle inside the picture, so a point closer to an edge than half the window cannot be centred — it is approached instead. Asking for a point 4.5 % down a page centres on 22.7 % when half the window is 1280 px and only 773 px of page lie above it. Every unreachable stop is named in the report with the coordinate it will actually land on. Putting a corner in the middle of the frame requires a surface behind the picture, which only tools/render_move.py and a composite provide.
The widest window is the base 9:16 rectangle. Past it there is no more picture. This ceiling is arithmetic and is enforced.
Enlargement is allowed and never silent. A window narrower than the 1080 px output stretches the source; there is no floor stopping it. The panel prints the factor while the rectangle is drawn, the report names it per scene, and on_upscale decides whether the render warns, refuses or stays quiet. For a 4096-px-wide page the 1:1 window is w = 0.264 and the deepest 9:16 push-in is 2.94×.
