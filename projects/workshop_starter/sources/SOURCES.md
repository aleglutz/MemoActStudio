# Sources — `workshop_starter`

Nothing here is archival and nothing here is published. The three images are
whatever the facilitator put in (see `../REBUILD.md`) and the recording is the
facilitator's or the student's own voice reading `../script.md`.

This file exists so the habit does. Every other project in this repository
records where each picture came from and under what licence, before the picture
is used rather than after; a starter project that skipped it would be teaching
the wrong reflex on the first morning.
